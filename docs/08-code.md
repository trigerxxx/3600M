# Код прототипа

Прототип режима «Один из нас стучит» на серых блоках. Код на Luau, проект для Rojo.

⚠️ **Код ещё ни разу не запускался.** Его писали без Roblox Studio. При первом запуске почти наверняка
найдутся ошибки: это нормально, их исправляем по сообщениям из окна Output.

## Как устроено
| Файл | Что делает |
|---|---|
| `src/shared/Config.luau` | Все числа баланса и цвета. Менять баланс — только здесь |
| `src/shared/Round.luau` | Правила раунда без привязки к карте: фазы, тепло, журнал, дверь, способности Гостя, голосование, победа. Это ядро движка для следующих игр |
| `src/server/Map.luau` | Строит станцию из серых блоков кодом и ставит подсказки (ProximityPrompt) |
| `src/server/Progress.luau` | Прогресс между раундами: уровни, задания дня, дни экспедиции, досье. Сохраняется в DataStore |
| `src/server/Analytics.luau` | Воронки аналитики: где уходят игроки (работает только в опубликованной игре) |
| `src/server/Look.luau` | Свет, цвет и эффекты: день, ночь, метель |
| `src/server/Main.server.luau` | Лобби, запуск раунда, связь правил с картой, рассылка состояния игрокам |
| `src/client/Main.client.luau` | Интерфейс игрока: фаза и таймер, тепло, журнал, стук, кнопки двери, панель Гостя, голосование |

Связь клиента и сервера: папка `ReplicatedStorage.Net` с тремя RemoteEvent:
- `Action` — действия игрока (запись в журнал, дверь, способности, голос). Сервер всё проверяет сам.
- `State` — снимок раунда 4 раза в секунду. Каждый игрок получает только то, что ему можно знать: чужие роли не отправляются.
- `Event` — разовые события (смена фазы, стук, кто замёрз, кого заперли).

## Как запустить (когда будет компьютер)
1. Установить **Roblox Studio** и войти в аккаунт.
2. Установить **Rokit** (менеджер инструментов): https://github.com/rojo-rbx/rokit
3. Скачать этот репозиторий и в его папке выполнить:
   ```
   rokit install
   rojo build -o 3600.rbxl
   ```
4. Открыть файл `3600.rbxl` в Roblox Studio.
5. Проверка на нескольких игроках: вкладка **Test** → **Clients and Servers** → выбрать **4 игрока** → **Start**.

Для постоянной работы удобнее режим живой синхронизации: `rojo serve` и плагин Rojo в Studio.
Тогда изменения кода из репозитория сразу попадают в Studio.

## Что уже работает в коде
- Лобби: старт при 4+ игроках через 10 секунд.
- Роли: метеорологи и Гость (2 Гостя при 7–8 игроках).
- Фазы: начало, день, ночь, совет, голосование, конец.
- Приборы: термометр, флюгер, барометр, снегомер → запись в журнал своим цветом.
- Печь, уголь, общее тепло, замерзание станции.
- Лампа в восточном окне, генератор.
- Ночной замер: один игрок снаружи должен постучать.
- Дверь: держать 3 секунды, «оттащить», глазок, настоящий и ложный стук.
- Гость: голос, подделка записи, тьма, следы, кража угля, метель; браслет моргает синим.
- Голосование и холодная кладовка.
