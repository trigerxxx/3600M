# Как работает алгоритм Roblox (ноябрь 2026)

По официальным материалам Roblox: Creator Hub (Discovery, Discovery FAQ) и новость о рекомендациях от июня 2026. Сторонние «секреты алгоритма» сюда не включены.

## 1. Где игроки находят игры
| Место | Как работает |
|---|---|
| **Главная: «Рекомендуем для вас»** | Главный источник. Персональная лента: сначала система отбирает игры, которые могут понравиться, потом ранжирует их для каждого игрока |
| Главная: «Продолжить», «Друзья играют», «Спонсорские», подборки | «Продолжить» возвращает старых игроков, «Друзья» — через друзей, «Спонсорские» — платная реклама, подборки (Standout Games, Live Events) делают люди из Roblox |
| **Страница игры** | Превращает интерес в заход: события игры, группа Roblox, пропуски и подписки, похожие игры |
| **Поиск** | Теперь смысловой: понимает запросы вроде «игры про выживание» на всех официальных языках |
| **Чарты и тренды** | Лучшие и растущие игры |
| **Уведомления игры** | Достижения, рекорды, активность друзей. Возвращают ушедших игроков. Игрок должен разрешить их в игре |

## 2. Что учитывает «Рекомендуем для вас» (по важности)
**Самое важное:**
1. **Начинают ли играть** те, кто увидел игру в ленте (play-through rate).
2. **Уходят ли сразу** в первой сессии (first-play bounce) — это минус.
3. **Сколько дней играют** (play days).
4. **Сколько времени играют** — учитывается не больше 60 минут на игрока в день.

**Важное:**
5. Дни, когда играют **с друзьями намеренно** (co-play).
6. Число полноценных сессий на игрока.
7. Дни с покупками.
8. Сколько Robux тратит игрок.

Время и дни считаются отдельно для **1-го дня, 2–7-го и 8–28-го**. Всё считается **в среднем на игрока**, а не суммой: маленькая игра не в проигрыше.

## 3. Как алгоритм пробует новые игры
«Разведка и расширение»: игру показывают небольшой группе. Если вовлечённость и покупки хорошие, её показывают похожим группам, потом шире. Плохой старт не наказывается навсегда: система продолжает пробовать игру на новых людях. Когда показов становится больше, доля начавших играть может временно просесть — это нормально.

## 4. ⚠️ Самое важное для нашего плана
**В ранжировании ленты «Рекомендуем для вас» учитывается вовлечённость только тех игроков, которые пришли из этой ленты.** Игроки из рекламы и других источников помогают игре **попасть на рассмотрение**, но их поведение на этом этапе не считается.

Что это значит для привлечения через ютуберов:
- Игроки из роликов **не поднимают игру в ленте напрямую**.
- Но они всё равно очень полезны:
  - помогают игре попасть на рассмотрение;
  - приносят деньги;
  - **приводят друзей** и создают совместную игру;
  - возвращаются через «Продолжить» и уведомления;
  - поднимают игру в чартах и трендах, «Друзья играют».
- А **решают судьбу в ленте** игроки, которые нашли игру на главной. Их удерживает качество игры: первые минуты, причина вернуться, игра с друзьями.

Поэтому разделение «автор приводит, Claude удерживает» остаётся верным, но главная роль удержания — **понравиться случайным игрокам из ленты**, а не только приведённым.

## 5. Правила, которые нельзя нарушать
- **Своя обложка обязательна.** Без неё игра вообще не попадает в рекомендации на главной.
- **Обложка, название и описание должны соответствовать игре.** Несовпадение — меньше рекомендаций и хуже позиции в поиске.
- **Оригинальные название и картинки.** Повторяющиеся названия и чужие или уже использованные картинки — минус.
- **Тренд — только со своим поворотом.** Игры, слишком похожие на существующие, могут ранжироваться ниже. Это подтверждает наш подход «формула 99 Nights, но своё исполнение».
- **Не обещать деньги** в описании и названии игры: такое не продвигается. Игра не должна держаться на промо-наградах.
- Соблюдать правила сообщества.

## 6. Что делаем в наших играх
| Действие | Зачем |
|---|---|
| Первые 60 секунд — сразу интерес (крушение, роль, первый стук) | Начинают играть, не уходят сразу |
| Задания дня, дни экспедиции, обновления | Больше игровых дней |
| Сессии 15–40 минут, «ещё один раунд» | Время в игре (до 60 минут учитывается) |
| Бонус за игру с друзьями, приглашения | Совместная игра |
| Честные косметические покупки | Дни с покупками |
| **Уведомления игры** (с разрешения игрока): «новое обновление», «друг побил твой рекорд» | Возвращают ушедших |
| **События игры** (Experience Events) на странице игры | Повод зайти сейчас |
| Группа Roblox для игр | Подписчики узнают о новых играх |
| Перевод на португальский и испанский | Смысловой поиск на всех официальных языках |
| 2–3 своих обложки, точно показывающих игру | Без обложки нет главной; точность — меньше уходов |
| В описании нет обещаний денег и наград | Иначе игра не продвигается |
