# Игра 4: Catch a Cloud («Поймай облако»)

**Одной фразой:** ловишь живые облака лассо, разводишь их на своём летающем острове, скрещиваешь и продаёшь погоду городам внизу.

## Почему именно такая игра
- **Другой жанр.** Первые три игры — хоррор и выживание. Четвёртая — симулятор, самый большой жанр Roblox по онлайну. По формуле `P(n) = 1 − (1 − p)^n` разные жанры делают попытки более независимыми: если одна аудитория не зацепилась, это не значит, что не зацепится другая.
- **Для всех возрастов.** Хоррор ограничивает аудиторию, а симулятор подходит и детям, и подросткам.
- **Проверенная схема плюс свежая тема.** Ловить, собирать, скрещивать, обмениваться — так устроены самые большие игры Roblox. Но облаков и погоды как живых существ почти никто не делал.
- **Сочная картинка сама собой:** радуги, молнии, северное сияние, золотые облака.
- **Связь со вселенной.** Погода — то, что записывают на метеостанции в «3600». Редкое облако «Метель 3600» и намёки на станцию в небе.

## Основной цикл
1. **Поймать.** Мимо острова проплывают облака. Бросаешь лассо: нажал и отпустил в нужный момент. Редкие облака быстрее и вёртче.
2. **Поселить.** Облака живут на твоём острове и **каждую секунду дают капли** (валюта), даже когда ты не в игре (с ограничением по времени).
3. **Скрестить.** Два облака рядом дают новое: дождь + солнце = радуга, снег + гроза = снежная гроза, туман + ночь = призрачное облако.
4. **Продать погоду.** Городам внизу нужны заказы: «Деревне нужен дождь», «Фестивалю нужна радуга». Награды больше, чем за простые капли.
5. **Улучшить.** Лассо подальше, остров побольше, вентиляторы, которые притягивают облака.

## Главная фишка: глобальные погодные события
Раз в час над **всеми серверами** проходит событие:
- 🌪️ **Суперячейка** — гигантская грозовая туча, внутри которой ловятся легендарные облака;
- 🌌 **Северное сияние** — облака на время становятся «сияющими», это редкая мутация;
- 🌈 **Двойная радуга** — капли ×2 для всех;
- ❄️ **Метель 3600** — шанс поймать редкое облако со станции.

Расписание видно в лобби. Игроки возвращаются **к событию**.

## Ветер: лёгкое «воровство»
Порывы ветра иногда сдувают облако с острова, если хозяин его не закрепил. Улетевшее облако может поймать **любой** игрок. У хозяина есть 10 секунд, чтобы свистнуть и вернуть его.
Это даёт азарт и моменты для клипов, но без злости: облако можно закрепить якорем, а новички защищены первые 30 минут.

## Обмен
Площадь обмена в небе: игроки меняются облаками. Обмен **только через окно подтверждения с обеих сторон**, вся проверка на сервере. Защита от дублирования предметов — обязательна с первого дня.

## Коллекция
**Облакопедия:** 60 видов облаков в первой версии, у каждого 3 мутации (обычная, золотая, сияющая). Пустые ячейки тянут вернуться.

## Удержание
- капли копятся, пока тебя нет: заходишь забрать;
- глобальные события по расписанию;
- задания городов на день;
- коллекция и мутации;
- обмен с друзьями, визиты на чужие острова, лайки островам.

## Монетизация (честная)
| Что | Тип |
|---|---|
| Скины лассо, острова, домика | Покупки |
| **«Погодный радар»**: показывает, какие облака летят через минуту | Game Pass |
| Второй остров, больше мест для облаков | Game Pass |
| Капли копятся дольше, пока тебя нет | Game Pass |
| Приватный сервер | Встроено |

**Не продаём** случайные яйца или сундуки за Robux и не продаём легендарные облака напрямую. Редкие облака только ловятся.

## Стиль
- острова в небе над морем облаков, закат и рассвет;
- облака — милые существа с глазами и характером: сонное, злое грозовое, радостное радужное;
- яркие насыщенные цвета по `09-art-direction.md`, но светлая палитра вместо ночной.

## Первая версия (5–7 недель)
- свой остров, лассо, 30 облаков, скрещивание, капли;
- 2 глобальных события (Суперячейка, Двойная радуга);
- задания городов;
- облакопедия;
- **обмен — только когда защита проверена**; если не успеваем, обмен идёт первым обновлением.

## Оценка
| | |
|---|---|
| Жанр | Симулятор, самый большой по онлайну |
| Конкуренция | Высокая, много похожих симуляторов. Выделяемся темой погоды и событиями |
| Шанс на 1000+ игроков в день | ~15–22% (оценка) |
| Потолок | Самый высокий из наших игр: у симуляторов бывают взрывные хиты |
| Доход на игрока | Высокий: игроки охотно покупают удобства |
| Риски | Обмен и дублирование предметов, баланс экономики, нужно много обновлений |
