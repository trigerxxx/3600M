# Игра 3 (идея): выживание в джунглях Амазонии

> Обновлено по формуле 99 Nights: см. раздел 7 в `14-99-nights-analysis.md` (центр — чинящийся самолёт, символ «Тот, что в листве», спасти 4 пассажиров, запуск в июне 2027).

Идея автора: частный самолёт разбивается в джунглях, выжил только ты. Нужно продержаться 33 дня, потом найти способ, чтобы тебя нашли.

## Предложенный поворот: поиск прекращают через 33 дня
По радио из обломков: «Поиски самолёта прекращаются через 33 дня». Цель — не просто прожить 33 дня, а **успеть подать сигнал до того, как тебя перестанут искать**. Таймер даёт напряжение с первой минуты.

Рабочее название: **«33 Days: Lost in the Amazon»** или **«Crash Site: Amazon»**.

## Основной цикл
- **День:** разбирать обломки самолёта на инструменты и материалы, искать еду и чистую воду, строить лагерь.
- **Ночь:** звуки джунглей, дождь, звери у огня. Держать костёр.
- **Голод, жажда, силы**, без сложной медицины.
- **Погода:** ливни поднимают реку и заливают низкий лагерь.

## Три пути спасения (финал)
1. **Починить рацию** из кабины: нужны детали, разбросанные по джунглям.
2. **Сигнал SOS** на песчаной косе: камни, костры, зеркало. Самолёт поиска пролетает в определённые дни.
3. **Плот вниз по реке** к посёлку: опасно, но не нужно ждать.

## Фишки
- **Обломки самолёта как главный ресурс.** Крыло — крыша, кресла — кровать, кабель — верёвка, топливо — сигнальный костёр. Такого в других играх про выживание почти нет.
- **Каждый раз новое место крушения** и разные детали рации.
- **Самолёт поиска** пролетает в случайные дни: успел зажечь костёр — шанс.
- **Тайна джунглей** (лёгкая): старые руины, чужой лагерь, записки другого выжившего.

## Совместная игра
Для сюжета «выжил только ты», а для игры **режим 1–6 игроков**: выжили несколько пассажиров. Делить еду, держать огонь по очереди, выбрать путь спасения вместе.

## Удержание
Разные самолёты (маленький частный, грузовой, гидроплан), умения выживших, коллекция находок, задание дня, рекорды «спасся за N дней».

## Стиль
Сочная картинка по `docs/09-art-direction.md`, но наоборот: **зелень, бирюзовая вода, оранжевые костры и закаты**. Хорошо контрастирует со снежными «3600» и «Whiteout».

## Оценка
| | |
|---|---|
| Жанр | Выживание, второй по популярности на Roblox |
| Главный конкурент | 99 Nights in the Forest («продержись N ночей в лесу»). Без своих фишек будут сравнивать |
| Сложность | Выше быстрых игр: крафт, звери, погода, большая карта. Примерно 8–12 недель |
| Общий код с «3600» | Частично: день и ночь, сохранение, магазин, перевод |
| Шанс на 1000+ игроков в день | ~12–18% (оценка) |

**Где в плане:** не быстрая игра на 3 недели, а вторая большая ставка. Разумно делать после «3600», когда движок и опыт уже есть. Порядок обсудить с автором.

## Что учесть
- Звери без крови: убегаешь, отпугиваешь огнём, теряешь силы.
- Без стереотипов о коренных народах Амазонии.

## Вступление в игре (15–20 секунд)
Идея автора: самолёт теряет управление и разбивается, как в кино, с видом спереди, после чего надпись.

| Время | Кадр |
|---|---|
| 0–3 с | Внутри самолёта: закат над джунглями, пилот шутит по рации, пассажиры — девочка с попугаем, повар, старый фотограф, игрок |
| 3–6 с | Гроза, молния бьёт в крыло, красные лампы, сирена, попугай мечется |
| 6–10 с | **Вид спереди:** камера впереди самолёта, он пикирует прямо на зрителя, за ним дым, внизу стена деревьев |
| 10–12 с | Удар о кроны, отрывается крыло, вспышка, белый экран |
| 12–15 с | Тишина, потом птицы. Игрок открывает глаза в обломках. Кресла пусты. Рация: «…поиски будут прекращены через 33 дня…» |
| 15–17 с | Надпись **«33 DAYS»** и «Найди их. Подай сигнал. Успей.» |
| 17 с | Управление сразу у игрока, прямо в обломках, без загрузки |

Правила:
- без крови и погибших: пассажиры **пропали**, а не погибли — это и есть цель игры;
- при повторных заходах вступление не показывается (можно пересмотреть из меню);
- делается кодом в Roblox: движение камеры, анимация самолёта, эффекты.

## Трейлер для рекламы (30 секунд)
| Время | Кадр |
|---|---|
| 0–6 с | Короткое крушение: вид спереди и удар |
| 6–9 с | Пробуждение в обломках, пустые кресла |
| 9–15 с | Нарезка: починка самолёта, загорается фара, плот на реке, друзья у огня |
| 15–20 с | Ночь. Рация говорит голосом пилота: «Я рядом… подойди к обломкам…». В листве поднимается силуэт |
| 20–24 с | Красная сигнальная ракета, силуэт отступает |
| 24–27 с | Самолёт поиска пролетает над джунглями мимо машущих игроков |
| 27–30 с | «33 DAYS. Then they stop searching.» и название игры |

Производство: рендер в Blender (как ключевой арт 3600) + кадры из игры. Автор делает раскадровку в Figma (6–8 кадров) и подбирает звук: рация, сирена, тишина, птицы.

## Что усилит шансы (из разбора)
- запоминающийся силуэт «Того, что в листве»: 3–5 вариантов в Figma, проверка на тестерах;
- **португальский и испанский с первого дня**: Амазония — тема, близкая игрокам из Бразилии и Латинской Америки;
- 6–8 еженедельных обновлений готовы **до** запуска;
- Discord-сообщество за 2 месяца до запуска;
- 1–2 заказа у художников на ключевые модели (самолёт, символ), $100–500.
