# Тизер «33 Days»: крушение

Черновик 12 секунд: самолёт с горящим двигателем пикирует над джунглями на закате прямо на камеру, врезается в кроны, отрывается крыло, вспышка → рация «…поиски будут прекращены через 33 дня…» → титул «33 DAYS».

- `teaser-33days.mp4` — готовый черновик.
- `resolve/` — проект для DaVinci Resolve: File → Import → Timeline → выбрать `teaser.fcpxml` (файлы должны лежать рядом с ним). Все куски уже разложены по дорожкам, звук на отдельной дорожке. Дальше правка на глаз: цвет, ритм, надписи.
- `resolve/stop.png` — карточка «THEN THEY STOP SEARCHING.» для полного 30-секундного трейлера.
- `source/` — как это сделано: `crash.py` (сцена Blender, строится кодом), `titles.py` (надписи), `sound.py` (звук), `fcpxml.py` (файл монтажа), `assemble.sh` (сборка черновика).

## Что улучшить в чистовом варианте
- Рендер в Full HD с большим числом сэмплов на видеокарте (компьютерный клуб или свой ПК): сейчас 640×360 на процессоре.
- Детальнее самолёт и джунгли (модели от художника или бесплатные CC0), объёмный дым и огонь.
- Кадр из салона перед падением (пассажиры, гроза, сирена) по раскадровке из `docs/10-amazon.md`.
- Настоящие звуки из библиотек с лицензией вместо синтезированных.
- Кадры игры после титула, чтобы трейлер честно показывал игру.
