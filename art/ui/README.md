# Макеты интерфейса

Экраны для телефона в горизонтальном положении, 1280×720. Файлы `.svg` — для Figma, `.png` — для просмотра.

| Файл | Экран |
|---|---|
| 01-role-reveal | Роль в начале раунда: метеоролог и Гость |
| 02-hud-day | День: верхняя панель, тепло, задания дня, подсказка у прибора |
| 03-hud-night-door | Ночь: стук, кнопки «Открыть», «Глазок», «Оттащить» |
| 04-journal | Журнал наблюдений и новая запись |
| 05-council-vote | Совет и голосование с уликами ночи |
| 06-guest-panel | Панель Гостя: очки холода и способности, пример браслета |
| 07-icons | Три варианта иконки игры |

## Как открыть в Figma
Перетащите `.svg` файл в окно Figma. Каждая часть экрана — отдельная группа с понятным именем
(`topbar`, `journal`, `door-buttons`, `guest-panel` и т. д.), текст остаётся редактируемым.
Шрифт в макетах — Inter, в журнале — Georgia (рукописный шрифт стоит подобрать).

Это черновые макеты: композиция, цвета и размеры кнопок. Финальную графику рисует автор.
