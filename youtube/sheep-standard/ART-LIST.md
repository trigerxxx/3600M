# Что нарисовать в Figma (список для автора)

Ориентир: `sketches/wolf-sheet.png`. Рисуй в своём стиле, эскиз только показывает идею.

## Стиль
- Нарочито «кривой» рисунок от руки: толстый чёрный контур 6–8 px, плоские цвета, без теней.
- Волк: скучающий полузакрытый глаз, один клык, всегда в костюме.
- Овцы: простые облака шерсти, чёрная морда, палочки-ноги.
- Фон в роликах белый. Рисунки отдавай на прозрачном фоне.

## Как отдавать файлы
- PNG с прозрачным фоном, волк высотой около **1200 px**, ноги касаются низа картинки.
- Для каждой позы волка три файла: `wolf_stand.png`, `wolf_stand_talk.png` (пасть приоткрыта), `wolf_stand_blink.png` (глаз закрыт).
- Овца — **отдельно тело-шерсть, голова и ноги**: так я смогу плавно уменьшать шерсть в анимации.
- Имена латиницей.

## Шаг 2 — всё для ролика «How Inflation Fleeces You» (~20 картинок)
**Волк (+ пасть и моргание для каждой позы)**
- [ ] стоит · протягивает лапу · с ножницами для стрижки · ставит печать · усмехается · пожимает плечами

**Овцы**
- [ ] пушистая (богатая) · средняя · остриженная (разорена) — тело отдельно от головы и ног
- [ ] морды: спокойная · грустная · в шоке
- [ ] стадо (5–6 овец вместе) · овца бежит
- [ ] костюмы поверх овцы: корона (правительство) · фартук (продавец) · платок и очки (бабушка) · каска (рабочий)

**Предметы**
- [ ] войлочная расписка «1 WOOL» · стопка расписок · печать Банка Волка
- [ ] ножницы для стрижки · клочки шерсти (3–4 штуки)
- [ ] пучок травы (товар) · прилавок · ценник (пустой, цифры добавлю я)
- [ ] тележка, полная расписок · доска (пустая)

## Потом
